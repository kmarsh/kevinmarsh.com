I've been using Raycast's ability to set hotkeys for apps in conjunction with [Hyperkey](https://hyperkey.app/) to create a set of single-letter-and-hyperkey shortcuts that'll quickly open or switch to my most frequrntly used applications:

![](https://cdn.remarkedusercontent.com/file/remarked-prod/1/marks/mmsJiqgx/20240419-110926.webp)

It's been mostly working great, when I can remember to use them... there's a problem, though: what key to use for each app?

The obvious choice is to use the first letter of the app's name, but that doesn't always work. For example, I have several apps that start with `S` (Slack, Spark, and Spotify) and two that start with `C` (Google Chrome and Visual Studio Code). The other option is to use a key that's a mnemonic for the app's function, but that's not always clear either. Ideally I'd like a consistnet system that I can remember and use without thinking.

| App | Name-based Key | Function-based Key
| -- | -- | -- |
| 1Password | **1** | **P**assword manager |
| Arc | **A** | **B**rowser |
| Google Chrome | **G** | **B**rowser |
| Messages | **M** | **C**hat |
| Obsidian | **O** | **N**otes |
| Reeder | **R** | **F**eed reader |
| Slack | **S** | **C**hat |
| Spark | **S** | **E**mail |
| Spotify | **S** | **M**usic |
| Visual Studio Code | **C** | **T**ext editor or **E**ditor |
| Zed | **Z** | **T**ext editor or **E**ditor |
